# terminal-games
A collection of little games that you can play from your terminal.

## Play

```sh
curl -fsSL https://raw.githubusercontent.com/BenjaminBenetti/terminal-games/main/play.sh | bash
```

The script downloads the latest release into a temporary directory, runs the
game picker, and cleans up when you quit. Nothing is installed. Linux only
(x86_64 or arm64).
